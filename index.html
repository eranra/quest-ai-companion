🥽 ⚠️ WebGPU Flag is Disabled

Meta Quest Browser has WebGPU turned OFF by default.

Local on-device AI (Qwen 2.5) requires WebGPU hardware compute shaders to run. Since the flag is disabled, local models cannot generate responses.

⭐ Recommended: Instant VR Chat 0 MB VRAM

Switch to Google Gemini Cloud. It requires zero browser flags, uses no headset memory, and answers in ~300ms!

🔧 How to enable WebGPU on Meta Quest 3:

  1. Open a new tab in Meta Quest Browser.
  2. Type chrome://flags in the address bar.
  3. Search for webgpu.
  4. Set WebGPU and Unsafe WebGPU to Enabled.
  5. Tap Relaunch at the bottom of the screen.
